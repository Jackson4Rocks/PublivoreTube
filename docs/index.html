THE APP

A TV interface that actually feels like a TV interface.

PublivoreTube is built around the remote: big targets, visible focus states, horizontal shelves, and simple navigation. The current Android TV build is already usable, while playback, account features, and polish continue to evolve.

● Android TV / Google TV● D-pad first● Open source● Official YouTube embedded playback

A NOTE ON SPONSORBLOCK

Segment data, not playback modification.

The current build can retrieve and display SponsorBlock segment information. It does not automatically alter standard YouTube playback.
